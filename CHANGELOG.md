# Changelog

All notable changes to Spellbook Ledger are listed here.

## [1.0.0] · 2026-11-24

First release.

### Collection
- Import ManaBox CSV exports, with Replace and Merge for later scans
- Warning before a Replace import would leave decks short of cards
- Grid and list views, with copies of a card stacked together
- Copy menu with a counter for each printing, foil and regular listed separately
- Filters for rarity, set, finish and tag, plus several sort orders
- Search syntax for name, set, rarity, finish, tags, price, quantity, language, condition, mana value, type and color identity
- Tagging, one card at a time or in bulk
- Card detail view with mouse tilt and holo foil shimmer
- "In deck" tags on cards used in decks

### Decks
- Commander, Brawl, Historic Brawl, Standard, Pioneer, Modern, Pauper, Limited and Casual formats
- Piles by mana value or card type, or a plain list
- Commander picker limited to legendaries you own, with partner and Background support
- Format rules: singleton, color identity and deck size
- Placeholder basic lands
- Owned / need counts, proxy marking, and a warning before reusing a copy across decks
- Decklist paste and export

### Other
- Edit collection tab: add from Scryfall, correct counts, remove cards, change history
- Card details and art from Scryfall, online or from an offline bulk data file
- Collection stats
- Settings menu
- Full backup and restore, and CSV export
- Desktop app for Windows and macOS via Electron
- First-launch intro animation
